# Changelog

## 0.2.0

- Added six color presets and custom card/accent colors per token.
- Added background image opacity, darkening, brightness, blur, sizing and position controls.
- Added live appearance preview beside the editor and an appearance reset button.
- Fixed relative background image URLs resolving against the stylesheet folder instead of Foundry's media base.
- Existing cards use classic appearance defaults; prototype token settings include appearance options.
- Validation: 11 automated tests and 17 browser interaction checks in the preview harness. Live Foundry/SWADE runtime validation remains separate.

## 0.1.0

- Initial release: token hover dossiers, configurable identity and lore, passive/active effect groups and inverse SWADE wound bars.
